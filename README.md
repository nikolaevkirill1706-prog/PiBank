# PiBank — этап 1

Что внутри: регистрация, вход, восстановление пароля, сохранение входа, главный экран,
создание карт vida (до трёх: дебетовая, кредитная, детская) с переворотом по нажатию.

## Как запустить

1. В Firebase Console создайте проект.
2. Добавьте Android-приложение с именем пакета `com.pibank.app`
   и скачайте `google-services.json` в папку `app/` (рядом с `app/build.gradle`).
3. Authentication → Sign-in method → включите «Email/Password».
4. Realtime Database → Create database → вкладка Rules →
   вставьте содержимое `database.rules.json` → Publish.
5. Откройте папку PiBank в Android Studio (нужен JDK 17, встроенный подойдёт),
   дождитесь Gradle Sync, подключите телефон и нажмите Run.

## Важно

- Валюта меняется в одном месте: `Money.java` (константа CURRENCY). Суммы хранятся в копейках.
- Баланс при создании карты всегда 0, менять его с телефона правила не позволяют.
- Лимит «три карты» пока проверяется в приложении. На этапе 2 создание карт переедет
  на сервер (Cloud Functions), и лимит будет жёстким.
