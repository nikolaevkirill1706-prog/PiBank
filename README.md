# PiBank — этап 2

Добавлено: серверные функции (Cloud Functions), переводы по номеру карты, история операций,
кредитные карты (сумма и срок), погашение кредита, автоудаление карт за неуплату.

## Как работают кредиты

- Кредитная карта создаётся с суммой (100–100 000) и сроком (3, 7, 14 или 30 дней). Деньги сразу на карте.
- До конца срока нужно вернуть сумму кредита. После срока долг удваивается.
- Если кредит не погашен ещё 3 дня после срока, сервер удаляет ВСЕ карты пользователя (включая детские).
- Проверка идёт на сервере каждые 30 минут, поэтому удаление может произойти с задержкой до получаса.

## Установка серверной части (один раз, из Codespaces)

1. В Firebase переведите проект на тариф Blaze (Upgrade в левом нижнем углу консоли).
2. В терминале Codespaces:

   npm install -g firebase-tools
   firebase login --no-localhost
   firebase use --add
   firebase deploy --only functions,database

   - login выдаст ссылку: откройте её, войдите в Google-аккаунт Firebase и вставьте код обратно в терминал;
   - use --add: выберите свой проект и введите псевдоним default;
   - на вопросы при деплое отвечайте Enter (или y).
3. Команда deploy сама загрузит и правила базы из database.rules.json.
4. git add . && git commit -m "stage 2" && git push — GitHub соберёт новый APK.

## Важно

- Баланс, карты и кредиты с телефона изменить нельзя: правила базы запрещают запись, всё идёт через функции.
- Валюта меняется в Money.java (CURRENCY) и в functions/index.js (функция money).
- Пополнение карт будет в PiBank Admin (этап 4).
